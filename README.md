# Tahir Siddique — Personal Site

Static personal site for [tahir-siddique.github.io](https://tahir-siddique.github.io/).

Python backend developer based in London, UK.

## Files

- `index.html` — single-page site (hero, about, experience, skills, education, contact)
- `styles.css` — layout and design
- `robots.txt` / `sitemap.xml` — crawl and indexing helpers
- `assets/tahir-siddique-python-developer.jpg` — headshot used for the page and Open Graph

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Repo → **Settings** → **Pages** → Source: **Deploy from a branch** → `main` / `/` (root) → Save.

## Search Console

1. Add property: `https://tahir-siddique.github.io`
2. Submit sitemap: `https://tahir-siddique.github.io/sitemap.xml`
3. After a week or two, check Images / web results for “Tahir Siddique Python”
